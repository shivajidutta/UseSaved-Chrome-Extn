# UseSaved Chrome Extension

**Save any URL in one click. Find it later with plain English.**

UseSaved is a personal knowledge library. Save anything from the web — AI automatically generates a summary, tags, and a semantic fingerprint. When you need something back, describe it in plain English and find it instantly, even months later.

---

## Install while Chrome Web Store review is pending

The extension is currently under Chrome Web Store review (1–3 days). In the meantime, install it directly in under 60 seconds:

### Step 1 — Download

Click **Code → Download ZIP** on this page → unzip the folder.

### Step 2 — Open Chrome extensions

Go to `chrome://extensions` in your browser address bar.

> Works in Chrome, Brave, Edge, and Comet (any Chromium browser).

### Step 3 — Enable Developer Mode

Toggle **Developer mode** ON in the top right corner.

### Step 4 — Load the extension

Click **Load unpacked** → select the `Chrome-Extn` folder you unzipped.

### Step 5 — Pin it

Click the puzzle piece icon in your toolbar → find UseSaved → click the pin icon.

The UseSaved icon appears in your toolbar. You're ready.

## How to use it

### Saving a page

1. Navigate to any page you want to save
2. Click the UseSaved icon in your toolbar
3. Add an optional note (why are you saving this?)
4. Click **Save This Page**
5. AI tags it automatically in the background — takes 15–20 seconds

### Searching your saves

1. Click the UseSaved icon
2. Click **Search my saves →** — the side panel opens
3. Type what you're looking for in plain English
4. Results appear ranked by relevance
5. Click any result to open it in a new tab

### Dashboard

Click **Dashboard** in the popup footer or side panel to open your full library at [app.usesaved.com](https://app.usesaved.com).
